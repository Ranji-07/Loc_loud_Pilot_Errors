# LocalPilot for VS Code

Thin client for the LocalPilot backend (default `http://127.0.0.1:8765`).

- Status bar item with overall backend health (click for details).
- Activity bar view: health checks and setup guides.
- Commands: `LocalPilot: Open Dashboard`, `Open Setup Guide`, `Show Usage`, `Show Health`, `Start Backend`.

Guided steps are executed by the backend only after you approve them in the dashboard.
